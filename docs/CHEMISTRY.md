# 계산 의미와 한계

화면의 “최적 구조”는 **입력 구조에서 찾은 국소 최적화 구조**다. 여러 conformer 또는 전역 최소점을 탐색하지 않는다. 최적화 수렴은 시작점 주변 stationary structure를 찾았다는 뜻이지, 가장 안정한 전체 구조를 증명하지 않는다.

## 프리셋

- 빠른 미리보기: `! R2SCAN-3C OPT`; 같은 wavefunction에서 전자구조를 읽는다.
- 표준: `! R2SCAN-3C OPT` 후 최적 좌표에서 `! PBE0 D4 DEF2-SVP TIGHTSCF SP`를 실행한다.

메서드 적합성은 계에 따라 다르다. 특히 음이온, 열린껍질, 전이금속에는 기본값이 부적절할 수 있다. 앱은 산화 상태나 스핀 상태를 추측하지 않으며 전하와 다중도를 사용자가 확인해야 한다.

전체 전자 밀도는 양의 scalar field 등치면이다. MO 표면은 파동함수 진폭의 `+c`와 `-c` 등치면이며 두 색은 확률의 부호가 아니라 **위상**이다. 등치면은 field 전체가 아니고 선택한 값의 표면이다. 여러 반투명 표면이 겹치면 WebGL depth sorting artefact가 생길 수 있다.

데모 결과는 UI 개발용 결정론적 좌표·오비탈 데이터다. 실제 에너지나 물리량이 아니며 화면에 `DEMO`로 표시된다.
